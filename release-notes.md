- Fixes the "Unhandled exception" error when opening Close All for the first time.
- New **Check for updates** button in the window and in the tray menu. From now on, updates install with one click.
- Errors are logged to `%APPDATA%\CloseAll\error.log` instead of showing a crash box.

**Updating from an older version:** download and double-click [CloseAll-Setup.bat](https://github.com/aduseii/CloseAll/raw/main/CloseAll-Setup.bat).
